About cathle 1.x v0.1✕

cathle 1.x v0.1

Nintendo 64 emulator for the browser · build 11.22.26
© AC Kondo 1999–2026 · Team Flames
R4300i interpreter, memory map and boot sequence ported from Project64 Legacy (pj64team), including its bit-accurate COP0/COP1 semantics (FCR31 cause/flag/enable bits, rounding modes, default NaNs, denormal traps). Low-level RSP runs each game's own microcode; a software RDP draws every frame. CIC-NUS-6105 algorithm © X-Scale.
